- Истории бэклога `docs/backlog.md` переименованы из `US-n` в `BL-n`, ссылки в `docs/00-project.md` обновлены.

## [lab-1] — 2026-10-19

### Добавлено
- Паспорт проекта `docs/00-project.md`: назначение, роли, сущности, стек, журнал запуска, структура проекта, карта функций, состояние практик, наблюдения о проблемах, выполнимость и план на семестр.
- Скрипт проверки работоспособности `tests/smoke_test.py`.
- Разделы README «Запуск», «Проверка работоспособности», «Протокол проверки запуска», «Статус требований», «Правила ведения репозитория».
- Лицензия MIT (`LICENSE`), каталоги `docs/adr/`, `docs/diagrams/`, `tests/`.
- `.python-version` (Python 3.13.3).
- Скрипт `.github/lab1-setup.sh` для настройки репозитория на GitHub: метки, защита `main`, issues.
- Состав команды из трёх человек с ролями, распределение работ и часов по участникам, правила командной работы в Git.

### Изменено
- Исходный код перенесён в `src/`. `.env` по-прежнему читается из корня репозитория.
- Зависимости зафиксированы точными версиями (`==`), включая транзитивные. Базовый образ — `python:3.13.3-slim`.
- CI запускает `manage.py` из `src/` и берёт версию Python из `.python-version`; раннеры закреплены на `ubuntu-24.04`.
- Дисциплина проекта — «Программная инженерия».

### Удалено
- `ИНСТРУКЦИЯ_ПО_ПРОЕКТУ.md` — инструкция по другой дисциплине.

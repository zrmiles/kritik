# Продуктовый бэклог и пользовательские истории

> **С ЛР 2 документ исторический.** Истории бэклога переименованы из `US-n` в `BL-n`, чтобы не путаться со сценариями `US-n`. Действующие требования и сценарии — в [01-requirements.md](01-requirements.md), соответствие BL → FR/US — в его [разделе 3.4](01-requirements.md#34-соответствие-бэклогу).

> Приоритеты по MoSCoW: **M** — must, **S** — should, **C** — could, **W** — won't (не в этой версии). Задачи ведутся как issues на GitHub с указанием исполнителя.

## Видение

**Для кого:** игроки, которые выбирают, во что поиграть дальше, и не доверяют рекламным обзорам.
**Проблема:** оценки в магазинах и у изданий смешаны с маркетингом, а обсуждения на форумах трудно свести к одному ответу «стоит ли».
**Решение:** каталог игр с оценками только от пользователей сервиса, удобным поиском и фильтрами, короткими рецензиями и личным списком «сыграть позже».

## Пользовательские истории

### BL-1. Регистрация и вход
**Как** посетитель, **я хочу** создать аккаунт и войти, **чтобы** мои оценки и список сохранялись.

- [ ] Форма регистрации: логин, имя на сайте (необязательно), пароль и повтор пароля.
- [ ] Слабый пароль, несовпадение паролей и занятый логин показываются у соответствующего поля.
- [ ] Неверный пароль при входе — сообщение «Неверное имя пользователя или пароль».
- [ ] После перезагрузки страницы пользователь остаётся авторизованным (до 7 дней).
- [ ] «Выйти» завершает сессию: после перезагрузки пользователь — гость.

### BL-2. Каталог из внешнего API
**Как** пользователь, **я хочу** видеть актуальный каталог игр, **чтобы** не искать сведения на других сайтах.

- [ ] Администратор загружает игры командой `import_rawg`; повторный запуск не создаёт дубликатов.
- [ ] У игры есть название, обложка (если есть), дата выхода, жанры, платформы; пустые поля не ломают страницу.
- [ ] На странице игры указан источник данных со ссылкой.
- [ ] Если RAWG недоступен, каталог открывается из сохранённых данных, ошибка видна в журнале импорта.

### BL-3. Поиск, фильтры, сортировки
**Как** игрок, **я хочу** сузить каталог по жанру, платформе, годам и оценке, **чтобы** быстро найти подходящую игру.

- [ ] Поиск по названию без учёта регистра, в том числе по-русски.
- [ ] Можно выбрать несколько жанров и платформ; жанры, платформа, годы, минимальная оценка и поиск применяются одновременно.
- [ ] При изменении одного фильтра остальные сохраняются; активные фильтры видны и снимаются по одному.
- [ ] Сортировка: по оценке, числу рецензий, новизне, году (старые сначала), названию.
- [ ] Число найденных игр совпадает с показанными результатами; при пустом результате — понятное сообщение и сброс.
- [ ] Состояние фильтров сохраняется в адресе страницы: ссылкой можно поделиться, кнопка «Назад» работает.

### BL-4. Страница игры
**Как** игрок, **я хочу** видеть на странице игры оценку сообщества и мнения игроков, **чтобы** решить, стоит ли играть.

- [ ] Средняя оценка с одним знаком после запятой и число рецензий; без рецензий — «Нет оценок», а не 0.
- [ ] Гистограмма распределения оценок 1–10.
- [ ] Рецензии можно отсортировать: новые, высокие, низкие.

### BL-5. Своя рецензия
**Как** авторизованный пользователь, **я хочу** поставить оценку и написать рецензию, **чтобы** поделиться мнением.

- [ ] Гость при попытке написать рецензию видит окно входа.
- [ ] Оценка 1–10 обязательна; текст — от 10 до 500 символов, счётчик символов виден.
- [ ] Одна рецензия на игру: после публикации вместо формы — моя рецензия с кнопками «Изменить» и «Удалить».
- [ ] Удаление требует подтверждения.
- [ ] После создания, изменения и удаления средняя оценка и число рецензий обновляются сразу.
- [ ] Чужие рецензии нельзя изменить или удалить (проверяется на сервере).

### BL-6. Личный список
**Как** игрок, **я хочу** отмечать игры «сыграть позже», **чтобы** не потерять кандидатов.

- [ ] Кнопка «В список» на карточке, в таблице и на странице игры; гостю предлагается войти.
- [ ] Страница «Мой список» показывает сохранённые игры, новые сверху; счётчик в меню.
- [ ] Список сохраняется между сессиями и недоступен другим пользователям.

### BL-7. Мои рецензии
**Как** автор, **я хочу** видеть все свои рецензии в одном месте, **чтобы** быстро их редактировать.

- [ ] Список рецензий со ссылками на игры, средняя оценка, которую ставит пользователь.
- [ ] «Изменить» открывает страницу игры сразу с формой редактирования.

### BL-8. Рейтинг сообщества
**Как** посетитель, **я хочу** сразу видеть лучшие игры по версии сообщества, **чтобы** начать с проверенного.

- [ ] На главной — игра с наивысшей оценкой, цитата из рецензии и следующие пять мест рейтинга.
- [ ] Блок скрывается, когда включены фильтры.

## Решения команды (зафиксированы)

| Вопрос | Решение |
| --- | --- |
| Шкала оценок | Целые числа 1–10 |
| Рецензий на игру от пользователя | Одна; можно изменить или удалить |
| Средняя оценка | Среднее арифметическое, выводится с одним знаком после запятой |
| «Выбор сообщества» | Средняя оценка 9,0 и выше |
| Источник игр | RAWG API (`import_rawg`), для офлайн-демо — `seed_demo` |
| Кто меняет игры | Только администратор (админка, импорт) |

# Тестирование

## Автотесты

```bash
python manage.py test          # 33 теста: API, права доступа, фильтры, импорт RAWG
ruff check .                   # линтер
```

Те же проверки запускаются в GitHub Actions при каждом push и pull request (`.github/workflows/ci.yml`), причём тесты там идут на **PostgreSQL**, как в продакшене.

| Файл | Что проверяется |
| --- | --- |
| `accounts/tests.py` | Регистрация, неверный пароль, дубль логина, восстановление сессии через refresh-cookie, отзыв токена при выходе, CSRF |
| `games/tests.py` | Сочетание фильтров, несколько жанров без искажения среднего, поиск по кириллице, диапазон лет, минимальная оценка, все сортировки, ошибки параметров, повторный импорт RAWG без дубликатов, журнал ошибок импорта, идемпотентность `seed_demo` |
| `reviews/tests.py` | Полный CRUD и пересчёт средней, одна рецензия на игру, границы оценки и длины текста, запрет менять чужую рецензию, «мои рецензии», распределение оценок |
| `saved_games/tests.py` | Добавление/удаление, повтор, несуществующая игра, приватность списка, флаг `is_saved` в каталоге |

## Чек-лист ручной проверки

Проходить перед демо на широком (≥1280px) и узком (375px) экране, в светлой и тёмной теме системы.

**Аккаунт**
- [ ] Регистрация нового пользователя
- [ ] Ошибки у полей: пустые поля, пароли не совпадают, слишком простой пароль, занятый логин
- [ ] Вход существующего пользователя
- [ ] Ошибка при неправильном пароле
- [ ] После перезагрузки страницы пользователь всё ещё авторизован
- [ ] Выход: «Мой список» и «Мои рецензии» просят войти

**Каталог**
- [ ] Поиск «мор» находит «Мор (Pathologic 2)», «ELDEN» — Elden Ring
- [ ] Два жанра + платформа + «с 2018» + «8+» дают согласованный результат, число «Найдено» совпадает с карточками
- [ ] Снятие одного фильтра крестиком сохраняет остальные
- [ ] Каждая сортировка меняет порядок; игры без оценок в конце при сортировке по оценке
- [ ] Пустой результат показывает «Пусто.» и кнопку сброса
- [ ] Переключение «Сетка / Таблица» запоминается после перезагрузки
- [ ] Ссылка с фильтрами, открытая в новой вкладке, показывает те же результаты; «Назад» возвращает предыдущие фильтры
- [ ] «Показать ещё» подгружает следующую страницу (проверить после импорта из RAWG, когда игр больше 24)

**Игра и рецензии**
- [ ] Игра без рецензий: «Нет оценок», пустая гистограмма, приглашение написать первую
- [ ] Гость нажимает «Написать рецензию» — открывается вход
- [ ] Без оценки и с текстом короче 10 символов форма не отправляется, ошибка понятна
- [ ] Публикация: оценка и гистограмма обновились, счётчик рецензий в шапке вырос
- [ ] Изменение оценки пересчитывает среднюю; у рецензии появляется пометка «изменено»
- [ ] Удаление с подтверждением пересчитывает среднюю
- [ ] Длинный текст (500 символов) и длинное название не ломают вёрстку

**Список**
- [ ] «В список» у гостя открывает вход, после входа игра добавляется
- [ ] Добавление/удаление меняет счётчик в меню без перезагрузки
- [ ] Список сохраняется после выхода и повторного входа
- [ ] Список одного пользователя не виден другому

**Импорт**
- [ ] `import_rawg` без ключа завершается понятной ошибкой, запись в журнале импорта со статусом «Ошибка»
- [ ] Повторный `import_rawg` не создаёт дубликаты (число игр в админке не растёт)
- [ ] Обложки RAWG отображаются; при битой ссылке показывается типографская обложка

## Учёт дефектов

Заводите баг как задачу на доске: шаги воспроизведения, ожидаемый и фактический результат, браузер/ширина экрана, скриншот. Исправление закрывается pull request со ссылкой на задачу и, если возможно, автотестом.
